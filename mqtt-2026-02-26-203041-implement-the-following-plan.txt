│ Plan: MQTT Event-Driven Architecture for Raspberry Pi Devices                │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ Currently, Raspberry Pi devices at each location poll the server via REST    │
│ API to check for new orders. This doesn't scale and causes unnecessary       │
│ traffic. We're replacing this with MQTT-based push notifications:            │
│                                                                              │
│ - Server pushes new orders to RPi devices via MQTT when Shopify webhooks     │
│ arrive                                                                       │
│ - RPi devices push fulfillment confirmations back via MQTT when customers    │
│ pick up                                                                      │
│ - Server remains the single source of truth (fulfillment table)              │
│ - Devices never talk to Shopify directly                                     │
│                                                                              │
│ The MQTT broker (Mosquitto) is already running in Docker with TLS. No        │
│ Laravel MQTT package exists yet.                                             │
│                                                                              │
