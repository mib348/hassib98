RPI Order Details — API Documentation

Base URL: https://dev.sushi.catering/api

POST /order_details_for_rpi

Submit a new order detail record.

FieldTypeRequired
order_idintegeryes
order_numberintegeryes
order_quantityintegeryes
opening_countobjectno
closing_countobjectno
openTimeintegerno
pre_img_namestringno
post_img_namestringno
current_datedatetimeno
pickup_datedatetimeno
order_locationstringyes
metafieldsobjectno

Example request:

POST /api/order_details_for_rpi
Content-Type: application/json

{
  "order_id": 123,
  "order_number": 1042,
  "order_quantity": 2,
  "opening_count": {"sushi_a": 5, "sushi_b": 3},
  "closing_count": {"sushi_a": 4, "sushi_b": 2},
  "openTime": 15,
  "pre_img_name": "pre_123.jpg",
  "post_img_name": "post_123.jpg",
  "current_date": "2026-02-10 14:30:00",
  "pickup_date": "2026-02-10 14:30:15",
  "order_location": "Standort 1",
  "metafields": {}
}

Response (201):

{"success": true, "data": { ... created record ... }}

GET /order_details_for_rpi

List all records. Optional query filters:

ParameterTypeDescription
order_locationstringFilter by location name
order_idintegerFilter by order ID

Example: GET /api/order_details_for_rpi?order_location=Standort+1

Response (200):

{"success": true, "data": [ ... array of records ... ]}

GET /order_details_for_rpi/{id}

Get a single record by ID.

Example: GET /api/order_details_for_rpi/1

Response (200):

{"success": true, "data": { ... single record ... }}

PUT PATCH /order_details_for_rpi

Update an existing record. Finds the record by order_id (or order_number) + order_location. Only sent fields are updated.

FieldTypeRequired
order_idintegerone of order_id / order_number
order_numberintegerone of order_id / order_number
order_locationstringyes
All other fields from POST are accepted (optional)

Example request:

PUT /api/order_details_for_rpi
Content-Type: application/json

{
  "order_id": 123,
  "order_location": "Standort 1",
  "closing_count": {"sushi_a": 3, "sushi_b": 1},
  "openTime": 22,
  "post_img_name": "post_123_v2.jpg"
}

Response (200):

{"success": true, "data": { ... updated record ... }}

Error (404):

{"success": false, "message": "Record not found."}
